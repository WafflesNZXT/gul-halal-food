# Future admin PWA

The public website and a future installable admin web app should share one authenticated order backend. The admin app must require secure staff sign-in and should never expose an unauthenticated public admin route.

Core screens: new-order notifications, order list, order detail, touch-friendly status changes, internal notes, event details, customer call/email actions when contact details exist, and later deposit/payment tracking. The backend should publish status updates to customer status links, support receipt/status-link resend actions, and keep private staff notes separate from customer-visible data.
