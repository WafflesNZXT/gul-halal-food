# Gul Halal Food

A Pakistani halal catering business website built with React, TypeScript, Vite, Tailwind CSS, and shadcn/ui components.

## Stack

- **Framework:** React 18 + TypeScript
- **Build tool:** Vite
- **Styling:** Tailwind CSS v4 + shadcn/ui (Radix UI)
- **Routing:** Wouter
- **Animations:** Framer Motion

## Running the app

```bash
PORT=5000 npm run dev
```

The dev server runs on port 5000. The workflow "Start application" is configured to do this automatically.
